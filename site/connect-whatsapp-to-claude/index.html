Client setup guide

Connect WhatsApp to Claude

To connect WhatsApp to Claude Desktop, link the WA MCP bridge with your phone and add the Python MCP server to Claude's configuration. For v0.1.0, use the manual configuration below. When a release includes the desktop extension, open its .mcpb file and select the same bridge configuration.

Link your phone first

Start the bridge with its configuration file. In WhatsApp, open Linked devices, select Link a device and scan the QR code in the local window. If you have only the terminal in front of you, you can scan its code instead. Wait for the phone to accept the link and for the bridge to begin receiving history before asking Claude about a conversation.

The bridge and Claude Desktop have separate jobs. The bridge maintains the device connection and stores messages. Claude launches a Python process to answer tool requests. Installing the Python package alone does not pair your phone. Leave the bridge running when you want Claude to see a newly arrived message or fetch an attachment that has not been downloaded.

Configure Claude Desktop

Install uv and make sure Claude can find its uvx executable. Open Settings, then Developer, then Edit Config in Claude Desktop. On Windows this opens the configuration under the Claude folder in AppData. On macOS the file lives in the Claude folder under Application Support in your user Library. Add the entry below to the existing server configuration and replace CONFIG_FILE with the absolute path on this machine. 

{
  "mcpServers": {
    "wa-mcp": {
      "command": "uvx",
      "args": [
        "--from",
        "wa-mcp-server==0.1.0",
        "--with",
        "wa-mcp-sdk[encryption,files]",
        "wa-mcp",
        "--config",
        "CONFIG_FILE"
      ]
    }
  }
}

The SDK extras allow this environment to read encrypted message fields and extract file text. Enter the command and each argument separately as shown. If the application cannot find uvx, use the path reported by where.exe uvx on Windows or command -v uvx on macOS. Quit the desktop application completely and reopen it to load the change.

Check what Claude can read

Ask Claude to run bridge_status. Look for a true database result, then check the connected and logged_in values under bridge. If the database result fails, check which configuration file you selected. If only the bridge is unreachable, check that the bridge process is running with the same API address and that both processes run as the user who linked the account.

Try asking for your five most recent chats. Pick one and ask for the context around its last invoice or meeting request. This checks that Claude can retrieve the original conversation after finding a match. If recent chats appear but an older exchange is missing, ask for history back to a particular date while the phone is online.

Choose which Claude connection you need

Claude Code also supports a local process. Its claude mcp add command accepts the server name followed by the executable and arguments. Choose user scope for access across projects or project scope for a project configuration file. The executable, SDK extras and absolute configuration path have the same meaning as in the desktop example.

For a local Claude Code session, run the command below after replacing CONFIG_FILE, then use claude mcp list to check the registered name. This registers the tool command with Claude Code. Claude Desktop still reads its own configuration when it starts. 

claude mcp add wa-mcp -- uvx --from wa-mcp-server==0.1.0 --with "wa-mcp-sdk[encryption,files]" wa-mcp --config "CONFIG_FILE"

A claude.ai custom connector uses a remote MCP service. Configure an HTTPS endpoint, enable OAuth on the server and enter the URL ending in /mcp in the connector. Approve the request on the server's consent page. This path involves hosting the service and managing access. For a single desktop connected to a local bridge, the configuration above is sufficient.

Questions

Will the extension download work for v0.1.0?

The v0.1.0 release has no .mcpb attachment. Use the manual entry on this page. For a release that lists wa-mcp.mcpb, open the asset, choose Install and select the bridge configuration in extension settings.

Can Claude send a message after installation?

Sending starts disabled. If you enable it, a client with MCP elicitation asks you to approve the exact send. Search, history reads and the daily overview are available while sending remains disabled.
