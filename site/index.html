own client.

Link your phone once. Choose where you want to ask the next question.

Bridge setup

Keep a linked bridge running and install uv. For the editor buttons, set WA_MCP_CONFIG to the absolute path of its config.json, then restart the client.

Claude DesktopRelease assets (.mcpb)
CursorAdd the stdio server
VS CodeInstall for agent mode

Claude Desktop v0.1.0 ships without the bundle. Use the manual configuration for this release.

Finish a pipx installation

Use Python 3.11 or newer. After installing the server, add the SDK extras for encrypted fields and file text. 

pipx inject --force wa-mcp-server 'wa-mcp-sdk[encryption,files]'

Set your client command to wa-mcp with --config and the absolute config path. Check the connection with bridge_status.

Security and privacy

Your store.
Your controls.

See what is protected
Encrypted fields
Message text and transcripts are encrypted by default with a key held for your OS user. Downloads and exports need separate protection.
Local by default
The bridge listens on loopback. Your MCP client receives the results it requests. Remote access is opt-in.
Sending starts off
Enable sending explicitly. Supported clients ask before each send. Other clients need a separate, weaker confirmation setting.

FAQ

Questions.

What does my assistant see?

Your assistant receives the results of the tools it calls. For example, a message search returns matching messages. A hosted assistant processes that content under its own terms.

Can I read messages from before I linked my phone?

Yes, when the phone supplies older history or you have a WhatsApp chat export. Request older pages from the phone or preview and import a TXT or ZIP file.

Do I need a second AI provider?

No. Your MCP client can interpret the tool results. Local rules detect tasks. A separate provider is optional for daily summaries and image descriptions.

Will WA MCP send messages automatically?

Sending is off by default. If enabled, a client with MCP elicitation asks for approval before a send. Once scheduled, a message can go out through the running bridge even when the assistant is closed.
