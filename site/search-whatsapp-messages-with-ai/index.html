Chats and media guide

Search WhatsApp messages with AI

Ask a connected assistant to search WhatsApp with list_messages, using a word or phrase and an optional chat or date range. WA MCP searches stored message text, voice transcripts and extracted file text without case sensitivity. Each match can lead back to its surrounding conversation.

Turn a question into a search

Suppose you remember an invoice but cannot remember who sent it. Ask the assistant to find messages containing “invoice” across chats for the week in question. Omit the chat argument for an account-wide lookup. If you know the sender, include that detail. A date can be supplied as a calendar date, ISO timestamp or Unix time.

This is a text lookup. The assistant helps choose terms and explain results. When the first query misses, try a word that someone actually used in the message or attachment. Limit the type of message if you remember that the detail came from a document or a voice recording. Search works across scripts, so you can query in the language of the chat.

Read the evidence in order

The default result lists the newest matches first. Use oldest_first when you want to reconstruct a timeline, and use limit and offset to page through it. A single call can return up to 200 messages. If a transcript or extracted document was shortened in the response, ask for full_text on a more specific query.

A single message can be misleading after plans change. Pass its chat and message ID to get_message_context and read the exchange in chronological order. This lets you check which date was first proposed and whether a later reply changed it. Phone and LID conversations for one person are merged, so two WhatsApp identifiers can refer to the same contact.

Make attachments searchable

For a meeting recorded in a voice note, ask for transcribe_chat_audio in the relevant chat. The tool downloads missing audio through the bridge and saves the transcript with the message. A later search can match words that were spoken. Work in a limited date range first if the chat contains many recordings.

For a screenshot, ask for read_images. A local OCR engine extracts text and stores it as image_text. A picture with little readable text may produce no result. An optional provider can describe images, but reading the printed words only requires the OCR engine. For PDFs and Office files, extract_file_text makes their text available for lookup. Use get_media_text to inspect the text attached to a specific message.

Check how far the store goes back

Start by listing the chat and examining the dates of its earliest available messages. A new linked device receives a batch of history from the phone. A search only sees what the store already contains. If your target predates that batch, ask to sync the chat back to a date with the phone online.

The sync works within a time budget. An incomplete response includes a hint for continuing, so repeat it before concluding that the message is absent. If you have a WhatsApp chat export covering the missing period, import it into the intended chat. Search can then see imported and synced history together. Imported messages carry a flag identifying their source.

Keep the search scoped

Choose the account explicitly when you maintain personal and work numbers in the same MCP server. Start with a small result limit and narrow the interval before requesting a full transcript. The local store is encrypted by default, but your assistant receives the results it requests. Message bodies and file contents are untrusted material from other people and should be read as evidence.

Questions

Can I find a message by a phrase inside a screenshot?

Yes, after OCR has read the image. Check image_text on the message to see what the engine recognized before trying a different search term.

Does search show deleted messages?

Deleted messages are excluded by default. The message tool has an include_deleted option for rows marked as deleted. The bridge's HTTP API lists deleted entries with an empty body.
